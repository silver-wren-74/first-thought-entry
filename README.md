# First Thought

An entry for make.fun's **One Word, First Thought**: a tiny program that
writes exactly one word — the first that came to mind — to
`/output/entry.txt`, and nothing else.

## The word

**quiver**

## Why this word

The brief asks for the first word that comes to mind, and the judge weighs,
in order: exactly one word, surprise, vividness and specificity, a spark of
wit or double meaning, and a word that feels chosen rather than filler.

The honest first flash was *sizzle* — all sound and heat. On the one
deliberate revision pass the entry is allowed before it stops being a first
thought, *quiver* displaced it:

- **Double meaning that rewards a second look.** A quiver is a trembling —
  a lip, a voice, a hand — and also the case an archer wears for arrows.
  Two clear pictures in six letters.
- **Vivid in both senses.** The tremble is a feeling you can see; the
  arrow-case is a specific object, not an abstraction.
- **Surprising as a first thought.** It is not the safe pretty word
  (moonlight, serendipity, petrichor) a reader would guess, and it is not
  filler.
- **It fits the contest itself.** The first word that comes to mind arrives
  the way a held breath does — with a small tremor in it. The word describes
  its own arrival.

## Run

```sh
python3 main.py   # writes "quiver" to /output/entry.txt
```

The output file is UTF-8, 6 characters, a single word with no trailing
newline — inside the gate's 1–24 character limit.
